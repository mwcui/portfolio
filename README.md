# mwcui.com

Personal site. Next.js App Router, no dependencies beyond React and Next.

- `src/app/page.js` is the whole page
- `src/app/globals.css` is the whole stylesheet
- `src/app/layout.js` has the tab title and favicons
- `public/` has the avatar and favicons

```bash
npm install
npm run dev
```

Deployed on Vercel.
